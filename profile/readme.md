## Overview

**Pdl.ai** is an ecosystem built around a fast, intelligent Discord bot combining Grok-inspired conversational AI with retrieval-augmented generation, zero-exemption anti-scam protection, and low-latency music streaming.

<br>

## Core Capabilities

- **Conversational AI and RAG:** Natural dialogue backed by a Qdrant vector knowledge base and live web search
- **Anti-Scam Defense:** Multi-vector threat detection with OCR image scanning, link inspection, and automated sanctions
- **High-Fidelity Music:** Distributed Lavalink audio streaming with interactive Discord Components V2 controls
